ABOUT THE PROJECT

About This System

The Barangay Health Care Appointment System is a simple front-end website made to help residents request an appointment at their local health center. It allows users to select a service, choose a date and time, and manage their appointment records.

Project type: Front-end website prototype

Tools used: HTML, CSS, and JavaScript

Note: Sample records are stored only on the device and browser where the website is opened.
